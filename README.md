# 🚀 SalesPilot AI

### AI-Powered Sales Analytics, Forecasting & Business Intelligence Platform

SalesPilot AI is an end-to-end intelligent sales analytics platform that transforms raw sales data into **actionable business insights, interactive analytics, machine-learning forecasts, and AI-powered recommendations**.

It provides a complete workflow from **data ingestion → preprocessing → exploratory analysis → KPI tracking → ML forecasting → AI-powered insights** through an interactive dashboard.

# 🤖 4. Machine Learning Forecasting

SalesPilot AI integrates machine learning models to predict future sales.

### Models Used

| Model             | Purpose                            |
| ----------------- | ---------------------------------- |
| Linear Regression | Baseline forecasting               |
| Decision Tree     | Non-linear relationships           |
| Random Forest     | Ensemble-based prediction          |
| XGBoost           | High-performance gradient boosting |

Models are evaluated using:

* **MAE** — Mean Absolute Error
* **RMSE** — Root Mean Squared Error
* **R² Score** — Coefficient of Determination

The best-performing model can then be used for future sales predictions.

# ⚙️ Installation & Setup

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/SalesPilot-AI.git

cd SalesPilot-AI
```

## 2. Create a virtual environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Configure Gemini API

Create an environment variable for your Gemini API key.

### Windows PowerShell

```powershell
$env:GEMINI_API_KEY="your_api_key"
```

### Linux / macOS

```bash
export GEMINI_API_KEY="your_api_key"
```

> Never commit your API key directly to GitHub.

For local development, you can also use Streamlit secrets.

```text
.streamlit/
└── secrets.toml
```

Example:

```toml
GEMINI_API_KEY = "your_api_key"
```

Make sure `.streamlit/secrets.toml` is included in `.gitignore`.

# 🧪 Model Evaluation

SalesPilot AI evaluates forecasting models using multiple metrics instead of relying on a single score.

### Mean Absolute Error

```text
MAE = average(|actual - predicted|)
```

Lower MAE indicates smaller average prediction errors.

### Root Mean Squared Error

```text
RMSE = √average((actual - predicted)²)
```

RMSE gives greater weight to larger prediction errors.

### R² Score

Measures how well the model explains the variance in the target variable.

Higher R² generally indicates a better fit.
